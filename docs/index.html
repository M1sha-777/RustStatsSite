One bot for Rust

Check player stats, servers, wipes, CCTV codes, raids, and skins in a few commands.

Responses pull from BattleMetrics, Steam, and in-game data so teams can make quick calls without tabbing out.

Getting started

  1. Add the bot to your Discord server.
  2. Run /help to see available commands.
  3. Try /ruststats or /rustinv on your Steam profile.
  4. Use Discord roles to control who can run admin-focused commands like /server.

Built for busy wipes

Replies include time zones, raid costs, and quick disclaimers so shot-callers can share info in voice without repeating themselves.

Snappy responses stay readable on mobile, keeping roam groups and builders on the same page.

Commands

/ruststats

Player stats from Steam and BattleMetrics.

Share KD, playtime, and recent servers to vet recruits fast.

/rustinv

Inventory value and top items.

Spot pricey skins and organize fair trades or giveaways.

/cctv

CCTV camera and pager codes.

Grab oil rig feeds and link them in Discord channels for quick references.

/wipe

Next global force wipe in your time zone.

Keep event reminders accurate across regions.

/server

Info for any Rust server by BattleMetrics ID, IP, or name.

See population trends, map size, and status before committing to a move.

/calculator

Simple raid calculator by target and weapon.

Estimate rockets, explo ammo, or satchels without opening spreadsheets.

/genetic

Genetic calculator for crops and clones.

Quickly check ideal seed combos and harvest timings.

/skins

Current weekly Rust store skins.

Share the store link or prices directly to clan chat.

/help

Short list of all public commands.

Use it as a fast reference when training new members.

Privacy Policy

This page describes how the RustStats Discord bot (“the bot”) handles data when you use it on Discord.

Data we receive

  • Discord user and guild information that Discord sends with each command (IDs, usernames, avatars, server IDs).
  • Command input you send to the bot (for example Steam IDs, server addresses, genomes).
  • Technical logs needed to keep the bot stable, such as error messages and performance metrics.

How we use data

  • To answer your commands: generate stats, calculations, and other responses.
  • To protect the service: rate limiting and abuse prevention.
  • To debug and improve the bot based on anonymous usage patterns.

What we do not do

  • We do not sell your data.
  • We do not use your data for advertising.
  • We do not read or log full message histories in your servers.

Data retention

Command usage statistics and technical logs may be stored for a limited time to keep the bot reliable. If you want your data removed, contact the maintainer via the official Discord server.

Contact

For privacy questions or requests, open a ticket or contact staff in the official RustStats Discord server.
