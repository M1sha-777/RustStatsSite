Built for Rust communities

RustStats Bot brings your favorite survival game data straight into Discord. The bot collects only the data it needs to respond to slash commands, then responds with concise embeds so your team can stay focused on the wipe.

Quick start

  1. Invite the bot to your server with the "Add to Discord" button.
  2. Use slash commands like /stats, /server, or /raid-calc.
  3. Customize channels and permissions with standard Discord roles.

Privacy Policy

Last updated: June 2024

Data we process

  • Discord metadata: user IDs, usernames, and guild IDs provided with each slash command.
  • Command content: the options you supply (player names, server IPs, etc.) to fulfill a request.
  • Game data: public Rust statistics fetched from third-party sources to build responses.

How we use data

The bot uses the data above only to generate responses to commands. Runtime caches are short-lived and are cleared when the process restarts. No marketing or profiling is performed.

Storage and retention

We do not maintain long-term databases. Temporary caches or logs may contain Discord IDs for operational troubleshooting and are routinely rotated.

Third parties

Game statistics are requested from publicly available Rust stat providers. Data is transmitted over HTTPS and is not shared with advertisers.

Your choices

  • Remove the bot from your server at any time via Discord's server settings.
  • Limit access using Discord roles and channel permissions.
  • Contact the maintainer to request log removal for your Discord ID if operational logs are present.

Contact

For privacy questions, open an issue on the GitHub repository or reach out to the maintainer via Discord.

Terms of Service

Last updated: June 2024

Acceptable use

  • Do not use the bot to harass, spam, or automate disruptive behavior in Discord servers.

The bot is provided on a best-effort basis. Downtime may occur during maintenance windows or when external Rust statistic services are unavailable.

Termination
