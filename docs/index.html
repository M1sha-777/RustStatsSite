One bot for Rust

RustStats is a Discord bot focused on Rust: player stats, inventories, servers, CCTV codes, raid math, genetics, and weekly skins in one place.

Data comes from Steam and BattleMetrics so you can quickly vet teammates, track servers, and plan moves without leaving Discord.

Getting started

  1. Add the bot to your Discord server.
  2. Run /help to see all commands.
  3. Try /ruststats or /rustinv on your SteamID64, vanity, or profile URL.
  4. Use Discord roles to decide who can run admin-only commands such as /server, /guilds, and /bot.

All features are modern slash commands; the bot does not use legacy text prefixes or read message content.

Built for busy wipes

Commands are tuned for wipe days: time zones and countdowns in /wipe, public or private toggles for /ruststats and /rustinv, and a compact raid calculator in /calculator.

CCTV and genetics utilities keep oil, farms, and base defense organised while replies stay clean on both desktop and mobile.

Commands

/ruststats

Rust player stats from Steam and BattleMetrics.

Pass any SteamID64, vanity, or profile URL and see playtime, KD, and recent servers.

/rustinv

Rust inventory value and top items.

Get total skin value plus a top 10 list to make trades and giveaways easy.

/server

Rust server info via BattleMetrics ID, IP:port, hostname, or connect string.

Check population, map, and status before committing your team to a wipe.

/wipe

Next global force wipe in your time zone.

Share accurate wipe countdowns across regions and platforms.

/calculator

Raid calculator by target and weapon.

Supports common doors, walls, deployables and weapons like C4, rockets, satchels, and explosive 5.56.

/cctv

Rust CCTV camera names and pager codes.

Grab oil rig and base camera IDs, with an extra button to reveal pager frequencies inside Discord.

/genetic

Rust genetic calculator.

Input parent genomes (e.g. YYYHHG YHYHHG) and plan optimal crops and clones.

/skins

Current weekly Rust store skins.

Post the weekly shop to clan chat and track cosmetics without opening the Rust store.

/help

Short list of all public commands.

Use it as a quick reference when onboarding new players to your server.

/guilds

Admin-only list of Discord servers that use the bot.

Useful if you manage multiple communities and want to audit where RustStats is installed.

/bot

Admin-only diagnostics for the bot.

Shows debug information and exposes a deep diagnostics button when you need more details.

Privacy Policy

This page describes how the RustStats Discord bot (“the bot”) handles data when you use it on Discord.

Data we receive

  • Discord user and guild information that Discord sends with each slash command or button interaction (IDs, usernames, avatars, server IDs).
  • Command input you send to the bot, such as Steam IDs, profile URLs, server addresses, and genome strings.
  • Technical logs with which command was run, basic timing, and error details to keep the bot stable.
  • Daily counters for how many commands each user and guild has run, stored in a small local JSON file to enforce configured limits.

How we use data

  • To answer your commands: generate stats, calculations, and other responses.
  • To protect the service: apply per-user, per-guild, or global daily command limits and prevent abuse.
  • To debug and improve the bot based on anonymised usage patterns and error logs.

What we do not do

  • We do not sell your data.
  • We do not use your data for advertising.
  • We do not read or log full message histories in your servers; the bot only works with slash commands, buttons, and basic guild metadata.

Data retention

Command usage statistics and technical logs may be stored for a limited time to keep the bot reliable. Daily limit counters reset every UTC day and are periodically overwritten. If you want your data removed, contact the maintainer via the official Discord server.

Contact

For privacy questions or requests, open a ticket or contact staff in the official RustStats Discord server.
