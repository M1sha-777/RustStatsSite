One bot for Rust

RustStats focuses only on Rust: player stats, inventories, servers, CCTV, raid math, genetics, and weekly skins.

Everything lives in Discord so teams decide faster on wipes, raids, and server moves.

Getting started

  1. Add the bot to your Discord server.
  2. Use /help to see available commands.
  3. Try /ruststats or /rustinv on any Steam profile (ID, vanity, or URL).
  4. Optionally lock commands like /server behind Discord roles.

All features are slash commands; the bot does not read normal messages.

Built for busy wipes

/wipe shows global force wipe time, /calculator returns raid costs, and utilities like /cctv and /genetic keep bases and farms organised.

Replies stay short and mobile friendly, easy to read in voice text channels.

Commands

/ruststats

Rust player stats: hours, KD, and recent servers from Steam and BattleMetrics.

/rustinv

Inventory value and top skins for any Steam account.

/server

Rust server search by BattleMetrics ID, IP:port, hostname, or connect link.

/wipe

Next global force wipe time in your time zone.

/calculator

Raid cost calculator for doors, walls, and deployables.

/cctv

List CCTV camera names and pager frequencies.

/genetic

Genetic helper for optimal crop and clone combinations.

/skins

Current weekly Rust store skins.

/help

Short list of all public commands.

Privacy Policy

This page describes how the RustStats Discord bot (“the bot”) handles data when you use it on Discord.

Data we receive

  • Discord user and guild information that Discord sends with each slash command or button interaction (IDs, usernames, avatars, server IDs).
  • Command input you send to the bot, such as Steam IDs, profile URLs, server addresses, and genome strings.
  • Technical logs with which command was run, basic timing, and error details to keep the bot stable.
  • Daily counters for how many commands each user and guild has run, stored in a local file to enforce configured limits.

How we use data

  • To answer your commands: generate stats, calculations, and other responses.
  • To protect the service: apply per-user, per-guild, or global daily command limits and prevent abuse.
  • To debug and improve the bot based on anonymised usage patterns and error logs.

What we do not do

  • We do not sell your data.
  • We do not use your data for advertising.
  • We do not read or log full message histories in your servers; the bot only works with slash commands, buttons, and basic guild metadata.

Data retention

Command usage statistics and technical logs may be stored for a limited time to keep the bot reliable. Daily limit counters reset every UTC day and are periodically overwritten. If you want your data removed, contact the maintainer via the official Discord server.

Contact

For privacy questions or requests, open a ticket or contact staff in the official RustStats Discord server.
